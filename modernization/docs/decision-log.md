# Decision Log — GenApp Policy-Issue Canonical Warehouse Bridge

> **Status — validated against local substitute, not AWS.** Every result this log refers to was produced on the
> local-substitute branch: a moto S3 endpoint in place of Amazon S3 and DuckDB in place of Amazon Redshift. The formal
> AWS diff requirement is OPEN and this has not yet happened. Nothing in this document may be read as closing it, and
> no row here records a provisioned AWS resource.

This log is the single rationale source for the whole `modernization/` tree. Every other artifact in that tree — Python,
COBOL, SQL, YAML, JSON, shell and Markdown — carries operational comments only and defers its "why" to a row below, so a
decision absent from this file is undocumented. Row IDs are stable and citable: `D-01` through `D-64` are assigned once,
sibling artifacts cite them by row subject, and no ID is renumbered or reused.

The five authorized COBOL and copybook sources — `base/src/lgapol01.cbl`, `base/src/lgapdb01.cbl`,
`base/src/lgapvs01.cbl`, `base/src/lgcmarea.cpy` and `base/src/lgpolicy.cpy` — are read-only and byte-identical to their
state before this work. Every claim below about the existing system carries an inline `[base/src/<file>:<locator>]`
citation, and no citation in this file points outside those five files. Diagrams belong to
`modernization/docs/architecture.md`; this file draws none and references figures by name instead.

Every row carries its ID, then the four things this record must state, one per column: what was decided, what
alternatives existed, why this choice was made, and what risk it carries. A sixth column names the evidence behind the
row and the artifacts it governs.
