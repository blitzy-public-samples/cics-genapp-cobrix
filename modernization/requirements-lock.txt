# Hash-pinned resolution of every distribution modernization/requirements.txt installs,
# direct and transitive, one exact version and one artifact digest each. It is the
# reproducible install path of this project:
#
#     modernization/.venv/bin/python -m pip install --require-hashes \
#         -r modernization/requirements-lock.txt
#
# pip refuses the whole install when any listed digest does not match the artifact it
# downloaded, when a listed distribution is not pinned exactly, or when the resolution
# needs a distribution this file does not list, so an install either reproduces this set
# byte for byte or does not happen. modernization/requirements.txt stays the
# human-facing manifest of the 10 direct pins; this file is generated from it and adds
# the 96 transitive distributions that resolution reaches. "make verify-env" measures
# both against each other: every direct pin has to stand here at the same version, and
# every entry here has to carry a sha256 digest.
#
# Platform of the resolution: CPython 3.12 on linux-x86_64 (manylinux). Each digest names
# the one artifact pip selected for that platform, so an install on another interpreter
# series, another operating system or another architecture selects a different artifact
# and is refused by the digest rather than resolving to an unpinned one. Re-generate this
# file on that platform to install there:
#
#     python3.12 -m venv /tmp/lock-resolve
#     /tmp/lock-resolve/bin/python -m pip install --upgrade pip==26.2.1
#     /tmp/lock-resolve/bin/python -m pip install --dry-run --report /tmp/resolve.json \
#         -r modernization/requirements.txt
#

# "download_info.archive_info.hashes.sha256" of each entry of "install" in that report.
